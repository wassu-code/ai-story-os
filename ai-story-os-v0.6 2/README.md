# AI STORY OS v0.6

日常二択型AIキャラクター運用OS。

## v0.6
- 前日・過去ネタ・実績を入力にした毎日の3案生成
- 「別の3案を出す」でネタだけ再生成
- 1案採用後、投稿文・A/B・画像/動画プロンプトを生成
- 結果画面で実データを保存
- 収益化ゲート: 検証 → 再参加 → CTAテスト → 小額課金 → 月額
- データ不足時は販売を勧めない
- SNS自動投稿・課金サービス接続は安全のため未接続

## Daily UX
1. 今日を開く
2. 3案から選ぶ（嫌なら別の3案）
3. 投稿を確認
4. 投稿後、結果の数字だけ入力
5. OSが次のネタと収益化段階を判断

## Deploy
Vercel Root Directory を `ai-story-os-v0.6` に指定してください。
