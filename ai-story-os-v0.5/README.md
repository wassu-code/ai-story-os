# AI STORY OS v0.5 — Daily Choice Edition

参加型AIキャラクターの日常を、視聴者の二択で翌日に反映する実験OS。

## v0.5の変更
- ホラー/サスペンス型を廃止し、服・髪・食事・仕事帰り・休日・部屋・習慣など日常二択へ変更。
- 運営者はAIの3案から1案だけ選択。視聴者にはA/Bの2択だけを見せる。
- 「昨日の選択 → 今日に反映 → 今日の二択 → 明日の結果」のChoice Chainを中心に設計。
- KPIを `VIEW → VOTE → RETURN → PROFILE → LINK → PAID` のファネルとして準備。
- v0.5では課金をLOCK。まずVIEW/VOTE/RETURNの参加需要を検証する。
- 画像/動画promptも、同じ成人キャラクター・日常・スマホ撮影風の一貫性を優先。

## 毎日の操作
1. `/today` で3案から1つ選ぶ
2. `/review` で投稿画像/動画と視聴者向けA/Bを確認
3. 公開を承認
4. `/results` で最重要改善点を1つだけ確認

## GitHub/Vercel更新
このフォルダ内のファイルを既存 `ai-story-os-v0.4` の中身と置き換えれば、VercelはGitHub commitを検知して自動再デプロイします。
